# Treat Pharmacy iOS

This repository contains the iOS companion app for the Treat Health nearest-pharmacy experience.

## Architecture

- SwiftUI app shell
- Core model for pharmacies and open hours
- Geolocation-driven nearest selection
- Clean, lightweight state model appropriate for a 50-credit MVP budget

## Run locally

Open the package in Xcode 15+ or use:

```bash
swift build
```

This project is intentionally lightweight and optimized for a polished MVP without excessive dependencies.
